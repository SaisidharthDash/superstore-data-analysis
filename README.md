# Superstore Data Analysis Using Python

# Project Overview
This project analyzes the Sample Superstore dataset to identify sales trends, profitability patterns, customer insights, and business performance using Python.

# Objectives
- Analyze overall sales and profit performance.
- Calculate key business KPIs.
- Identify monthly sales trends.
- Evaluate the impact of discounts on profitability.
- Generate visualizations to support data-driven decision-making.

 # Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter/VS Code

# Key Performance Indicators (KPIs)
- Total Sales: $2,297,200.86
- Total Profit: $286,397.02
- Profit Margin: 12.47%
- Total Orders: 5,009
- Total Customers: 793
- Average Delivery Time: 4 days

# Key Findings
- Sales generally increased over the period from 2014 to 2017.
- Higher discount bands were associated with lower average profit per order.
- The analysis highlights sales trends and profitability differences that can support business decisions.

# Project Files
- `superstore_analysis.py` — Python script for data cleaning, analysis, and chart generation.
- `charts/` — Generated data visualization images.
- `superstore_cleaned.csv` — Cleaned dataset generated by the script (not included in this repository).

# How to Run
1. Install Python.
2. Install the required libraries:

   ```bash
   pip install pandas matplotlib seaborn sqlalchemy pymysql
   ```

3. Update the dataset path in the Python script to match your local CSV file.
4. Run the script:

   ```bash
   python superstore_analysis.py
   ```

5. View the generated charts in the `charts` folder.

# Note
The script can perform the analysis and generate charts without MySQL. Loading data into MySQL requires a running MySQL server and valid connection settings.
